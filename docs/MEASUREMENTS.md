# Initial local measurements

Measured on 2026-09-06 with the release build, Rust 1.95.0, Windows 11 Pro
10.0.26200, Intel Core i7-13700K and NVIDIA GeForce RTX 4080 SUPER
(driver 32.0.16.1656). Window: 1080 × 740 at 100% display scale.
The machine was not dedicated to benchmarking. These are observations, not
performance guarantees or comparisons against other viewers.

The corpus is generated by `examples/fixtures.rs`. Its gradients and repeating
patterns compress unusually well; it does not represent a real photography
corpus. Reproduce using [PERFORMANCE.md](PERFORMANCE.md).

## File open and decode

One sequential pass of `kova-bench`, with no OS cache reset:

| Format | Dimensions | Retained RGBA bytes | Open + decode (ms) |
| --- | --- | ---: | ---: |
| JPEG | 1920 × 1080 | 8,294,400 | 5.785 |
| PNG | 1920 × 1080 | 8,294,400 | 5.127 |
| WebP | 1920 × 1080 | 8,294,400 | 6.143 |
| Large PNG | 6000 × 4000 | 96,000,000 | 167.876 |

## Startup observation

Five consecutive hardware-rendered launches of the generated JPEG recorded
process-main to first image render completion: **217.679, 197.657, 205.587,
194.552 and 215.863 ms**. Median: **205.587 ms**. External launch-to-observation
was 237.469–571.774 ms, including launcher overhead and polling granularity.
This is not a disk-cold startup experiment.

Three software-renderer launches recorded image-ready times of **23.311,
32.549 and 24.457 ms**. The renderer does not provide the same completion
callback: **these are not first-render timings and cannot be compared directly**
to the hardware numbers. Software UI rendering was separately smoke-tested.

## GIF CPU and memory

The generated 400 × 240, 12-frame GIF was sampled for approximately ten seconds
per phase, after an initial two-second settling period. Percentages are process
CPU time divided by elapsed time for **one logical CPU**, not whole-machine CPU.

| State | Process CPU time (ms) | One-core CPU (%) | Private bytes | Working set bytes |
| --- | ---: | ---: | ---: | ---: |
| Playing | 125 | 1.248 | 115,572,736 | 108,765,184 |
| Paused | 0 | 0 | 115,572,736 | 108,802,048 |
| Minimized, playback enabled | 0 | 0 | 103,460,864 | 108,802,048 |

Zero means no increment at the Windows process CPU counter's sampling
resolution during that interval, not a universal zero-CPU guarantee. Peak
working set observed in this run was 109,830,144 bytes. No memory-leak conclusion
is drawn from these short samples.

The release EXE observed during this validation was about 15.1 MB (decimal).
Portable ZIP size depends on the included documentation/license bundle.
Long-session navigation, diverse animations, truly cold launches, clean-machine
runtime dependencies, slower GPUs and older Windows hardware remain unmeasured.
